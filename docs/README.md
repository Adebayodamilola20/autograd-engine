# nabla — documentation

A from-scratch reverse-mode automatic differentiation engine, and a neural
network trained with it to 97.63% on MNIST.

These documents are meant to be read in order. They are the reasoning behind
the code, not a substitute for it — every claim here is implemented in
`nabla/` and pinned by a test in `tests/`.

## The shortest possible summary

```python
from nabla import Value

a = Value(2.0, label='a')
b = Value(3.0, label='b')
d = a * b + a

d.backward()

a.grad   # 4.0  =  b + 1
b.grad   # 2.0  =  a
```

Three lines of arithmetic build a graph. `backward()` walks it in reverse
topological order, multiplying local derivatives, and every leaf ends up
holding its partial derivative of the output.

Scale that to 109,386 parameters and you have a neural network that reads
handwriting.

## Running things

```bash
python examples/basic_autograd.py        # the engine, explained by example
python examples/backprop_step_by_step.py # one backward pass, narrated
python examples/gradient_check.py        # every rule vs finite differences
python examples/train_xor.py             # the smallest real network
python examples/train_mnist.py           # 97.63%, ~16 s

python -m pytest                         # 737 tests
python benchmarks/compare.py             # vs PyTorch
python experiments/run_all.py            # the Phase 22 sweeps
python web/server.py                     # the interactive demo
```
