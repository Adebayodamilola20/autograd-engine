      How this works underneath

      The graph

      Each operation builds a node holding its result, its parents, and a closure that knows its own local derivative. Running the forward pass is building the graph.

      The chain rule

      backward() topologically sorts that graph, seeds ∂L/∂L = 1, and walks it in reverse, multiplying local derivatives as it goes. Every gradient falls out of that one sweep.

      Why it's fast enough

      Because a node is a whole tensor, not a single number. Same mathematics, same gradients — but 285,000× faster than the scalar version, and within 1.2× of PyTorch per epoch.

      Verified, not assumed

      Every backward rule is checked against finite differences, (f(x+ε) − f(x−ε))/2ε, across 692 tests. A derivative you have not checked numerically is a guess.
